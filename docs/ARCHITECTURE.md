# SatX Project Architecture

## Repository Layers

```code
configs      Different experiment configurations
data         Local dataset files, not tracked by Git so far
docs         Documents
notebooks    Jupyter notebooks here
outputs      Raw Experiment outputs, not tracked by Git so far
report       Report figures and tables
results      Some experiment result
scripts      Commandline scripts
src/satx     Reusable Python package code
tests        Lightweight tests
```
